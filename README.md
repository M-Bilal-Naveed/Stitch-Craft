#🧵 Stitch Craft

Stitch Craft is a fully offline React Native + Expo mobile application built specifically for small tailor shops and tailoring businesses.

It uses SQLite for local data storage and authentication, allowing shop owners to manage their customers, measurements, orders, payments, and stitching progress without requiring an internet connection.

📱 Application Overview

Stitch Craft provides a simple way for tailor shops to manage their daily business operations from a mobile device.

👥 Customer Management

Shop owners can add customers and keep their information organized in one place.

You can easily:

Add new customers

Search existing customers

View customer details

View customer measurements

View customer order history

📏 Customer Measurements

Each customer can have their measurements stored locally.

This makes it easy to access measurements whenever the customer places a new order.

🧵 Order Management

Orders can be created for individual customers and tracked throughout the tailoring process.

Each order can have a current status such as:

Pending
   ↓
Cutting
   ↓
Stitching
   ↓
Ready
   ↓
Delivery


This allows the tailor to quickly see where an order currently stands.

💰 Payment Tracking

Stitch Craft also helps manage order payments.

For every order, you can keep track of:

Total order amount

Advance payment

Remaining balance

This makes it easier to know how much has already been paid and how much is still due.

🔍 Quick Search

The application provides customer search functionality so shop owners can quickly find a customer and access their:

Customer information

Measurements

Orders

Order status

Payment information

🌙 Light & Dark Mode

Stitch Craft supports both:

☀️ Light Mode

🌙 Dark Mode

The interface can be used comfortably in different lighting conditions.

🔒 Offline First

Stitch Craft is designed as a fully offline application.

All important business information is stored locally using SQLite, including:

Customer information

Measurements

Orders

Order statuses

Advance payments

Remaining balances

Authentication data

The application does not depend on an internet connection for normal day-to-day operation.

This makes it particularly useful for small businesses that want a simple and reliable way to manage their tailoring work.

🏪 Built for Small Businesses

Stitch Craft is designed with small tailor shops in mind.

Instead of relying on notebooks or complicated business management systems, shop owners can keep their customer and order information organized in a single mobile application.

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Node.js

npm or yarn

Expo CLI / Expo development environment

Android Studio or a physical Android device (for Android development)

Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL


Navigate to the project:

cd stitch-craft


Install dependencies:

npm install


Start the Expo development server:

npx expo start


You can then run the application using:

Android Emulator

iOS Simulator

Expo Go

Development build
